# 投胎轉轉（韭菜輪迴版）

台股崩了先別慌，來算算下輩子。閻羅王先問 5 題、算出這輩子的功德，再轉輪迴轉盤決定你下輩子投胎成什麼。

- 純屬娛樂。Copyright © 2026 大樹

## 玩法規則
- 功德值從 50 開始，每題答案會加減功德（0～100）。
- 轉盤有 6 種下輩子，每種有一個「功德中心值」：金湯匙 92、柯基 72、工程師 54、流浪貓 36、小螞蟻 18、韭菜 2。
- 權重 = exp(-((功德 − 中心值)/22)²) + 0.03，正規化後就是機率。所以功德再高，還是有一點機會變韭菜。

## 檔案
| 檔案 | 用途 |
|---|---|
| `index.html` | 整個 App（HTML＋CSS＋JS 內嵌） |
| `version.json` | 目前版號，給自動更新檢查用 |
| `v1-apple-touch-icon.png` | 主畫面圖示（檔名帶版號） |
| `splash/v1-*.png` | iPhone 啟動圖，各機型尺寸（檔名帶版號） |

## 改版流程
1. 改 `index.html`。
2. 要進版時，以下三處要改成同一個版號：`APP_VERSION`、`CHANGELOG`（最新的放最上面）、`version.json`。
3. commit 訊息第一行寫「vX.Y.Z：重點」，再 push。GitHub Pages 約 1～2 分鐘後更新。
4. 已經裝在桌面的 App 會在開啟或叫回前景時檢查 `version.json`，發現新版就自動重新載入。

## 踩過的坑
- iPhone 只在「加入主畫面」那一刻讀圖示和啟動圖，所以要換圖就得換檔名（v1 → v2），再請使用者刪掉桌面圖示、重新加入。
- 開機畫面固定用淺色（#f4efff），跟啟動圖同色，用來遮住 iOS 深色模式啟動時會插入的那一格白畫面。
- 「看過的版本」只能往前記，免得舊快取頁把紀錄倒回去，害更新說明每次都跳出來。
- 音效要在 click 事件裡才初始化，iPhone 需要使用者先點一下才能出聲。
